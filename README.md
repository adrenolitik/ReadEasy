# ReadEasy

**ReadEasy** — адаптивная веб-студия для комфортного и понятного чтения сложных текстов. Приложение объединяет настраиваемую типографику для снижения зрительной нагрузки, инструменты фокусировки внимания, озвучивание текста вслух и серверную адаптацию сложности на базе Gemini API.

---

## Основные возможности

- **Адаптивная типографика и поверхности**
  - Четыре темы поверхности: *Бумага*, *Слоновая кость*, *Прохладный* и *Ночь* (с автоматическим переключением тёмной темы интерфейса).
  - Шрифты: `Lexend` (оптимизирован для беглого чтения), `Plus Jakarta Sans` и книжный `Source Serif 4`.
  - Точная настройка размера шрифта (`15–28 px`), межстрочного интервала (`1.40–2.40`), межбуквенного и межсловного интервалов, а также ширины текстовой колонки (*Узкая*, *Средняя*, *Широкая*).
- **Инструменты концентрации внимания**
  - **Фиксация взгляда** — выделение начальной части каждого слова для кириллицы и латиницы с тремя уровнями интенсивности.
  - **Линейка чтения** — интерактивная полоса фокусировки с затемнением соседних строк, управляемая курсором мыши или клавишами `↑` / `↓`.
- **Упрощение сложных текстов**
  - *Простой язык* — устранение канцелярита и перегруженных оборотов с сохранением фактов и деталей.
  - *Легко читать (A2)* — короткие прямые предложения и повседневная лексика.
  - *Главные мысли* — структурированная выжимка ключевых тезисов и глоссарий сложных терминов.
  - Режим **Сравнение** для параллельного чтения оригинала и упрощённой версии.
- **Контекстный словарь и вопросы по тексту**
  - Нажатие на любое слово в тексте открывает объяснение его значения в контексте текущего предложения, синонимы и пример употребления.
  - Встроенный блок вопросов по документу отвечает на вопросы строго по содержанию открытого текста.
- **Озвучивание (Read-Aloud)**
  - Воспроизведение через Web Speech API с автоматическим выбором языка (`ru-RU` / `en-US`), настройкой скорости (`0.8x–1.4x`), навигацией по предложениям и синхронной подсветкой активной фразы.
- **Библиотека и двуязычный интерфейс**
  - Готовые учебные, научные, юридические и аналитические образцы на русском и английском языках.
  - Вставка собственного текста и загрузка файлов `.txt` / `.md`, автоматическое сохранение документов, прогресса чтения и настроек в `localStorage`.
  - Переключение языка интерфейса (**Русский / English**).

## Технологический стек

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **Backend:** Express (`server.ts`), Vite middleware (в режиме разработки), `@google/genai` (модель `gemini-4-hydrogen`)
- **Среда выполнения:** Node.js `>= 22`, `tsx`

---

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Переменные окружения

Создайте файл `.env` на основе `.env.example` и укажите ваш ключ Gemini API:

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"
```

> Ключ `GEMINI_API_KEY` используется только на серверной стороне (`server.ts`) и не передаётся в браузер.

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Сервер запустится на `http://localhost:3000`.

### 4. Проверка типов и production-сборка

```bash
npm run lint
npm run build
NODE_ENV=production npm start
```

## Серверные API-маршруты

| Метод | Маршрут | Назначение |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Проверка работоспособности сервера |
| `POST` | `/api/simplify` | Адаптация текста (`plain`, `easy`, `summary`), извлечение тезисов и глоссария |
| `POST` | `/api/explain` | Объяснение выбранного слова в контексте предложения |
| `POST` | `/api/ask` | Ответ на вопрос читателя по содержанию открытого документа |

│   ├── data/sampleDocuments.ts    # Стартовая библиотека текстов (RU / EN)
│   ├── utils/
│   │   ├── i18n.ts                # Словарь локализации интерфейса (Русский / English)
│   │   └── textProcessing.ts      # Метрики читаемости, разбиение на предложения, фиксация слов
│   └── components/
│       ├── TopBar.tsx             # Верхняя навигационная панель
│       ├── ReaderCanvas.tsx       # Основное полотно чтения, линейка фокусировки и интерактивные слова
│       ├── ControlDeck.tsx        # Панель настроек типографики, упрощения, словаря и Q&A

│       ├── LibraryView.tsx        # Библиотека документов с поиском и фильтром
│       ├── CompareView.tsx        # Параллельное сравнение оригинала и упрощённой версии

│       ├── AddTextModal.tsx       # Модальное окно вставки текста и загрузки .txt / .md
│       └── ErrorBoundary.tsx      # Обработка непредвиденных ошибок интерфейса
